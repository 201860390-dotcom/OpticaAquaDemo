# Óptica Aqua — Prototipo V2

## Descripción
Prototipo mejorado de la página web de Óptica Aqua, combinando lo mejor de las versiones anteriores (ClaudeOpus y ClaudeOpusThinking). El diseño es formal, profesional y elegante, sin emojis, con una paleta de acuarios sobria y tipografía sofisticada.

## Archivos incluidos

```
prototipoV2/
├── index.html      # Página de inicio
├── catalogo.html   # Página de catálogo con productos
├── styles.css      # Estilos base y variables globales
├── home.css        # Estilos específicos de la página de inicio
├── catalogo.css    # Estilos específicos del catálogo
└── script.js       # Funcionalidades interactivas
```

## Características

### Diseño
- **Tipografía profesional**: Cormorant Garamond (serif), Inter (sans), Space Grotesk (display)
- **Paleta de acuarios**: Tonos profundos y elegantes (#0a3d3d, #1a6b6b, #2d9e9e, #7ec8c8)
- **Estética formal**: Sin emojis, limpio y corporativo
- **Animaciones suaves**: Transiciones sutiles y profesionales

### Funcionalidades
- **Preloader animado**: Transición suave al cargar la página
- **Header fijo con efecto scroll**: Se adapta al hacer scroll
- **Menú móvil responsive**: Hamburguesa toggle
- **Catálogo de productos**: Más de 200 modelos con filtros por categoría
- **Smooth scroll**: Navegación fluida a través de anclas
- **WhatsApp flotante**: Botón de contacto directo

## Instrucciones de uso

1. Descargar todos los archivos en una carpeta
2. Abrir `index.html` en el navegador
3. Navegar a `catalogo.html` para ver el catálogo completo

## Estructura de datos de productos

El catálogo utiliza los siguientes datos extraídos del inventario real de Óptica Aqua:
- **Marcas**: MARINA, FOFO, SM, ROWAN, DANIEL PARKER, PRINCE NOBLE, CAFFSEN, C-MARK, LOTUS, WHARTON, LATIV, y más de 30 marcas
- **Categorías**: Mujer, Hombre, Niños, Deporte, Industrial
- **Materiales**: Pasta, Acetato, Metálico, Titanio
- **Colores**: Negro, Azul, Dorado, Plata, Café, Carey, Transparente, y más

## Notas
- Las imágenes de productos deben colocarse en la carpeta `imagenes/`
- El prototipo está optimizado para dispositivos móviles y de escritorio
- No utiliza emojis para mantener una estética profesional y formal
